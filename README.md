# Сборка FBS

Загрузите сборочное задание Excel WB, проверьте сводную таблицу и скачайте PDF A4 для печати.

Во вкладке «Объединить CSV» выберите сразу несколько CSV с кодами маркировки для ТЕКШЕР и скачайте один общий файл. Можно добавлять файлы несколькими партиями, удалять отдельные файлы и задавать имя результата.

## Объединение CSV
- Вход: CSV без заголовков, один код в строке, общий размер до 100 МБ.
- Строки объединяются в порядке добавления файлов. Повторы сохраняются; при скачивании показывается их число.
- Содержимое каждой строки копируется побайтово: ведущие нули, запятые, кавычки, пробелы и управляющие разделители GS сохраняются.
- Убираются пустые строки и начальный UTF-8 BOM каждого файла. Переносы строк результата — CRLF, без BOM и добавленных заголовков.
- UTF-16 и файлы с нулевыми байтами отклоняются с предложением сохранить CSV UTF-8. Остальные файлы должны иметь одинаковую кодировку; преобразование кодировки не выполняется.
- Обработка полностью в браузере. Исходные файлы и коды не отправляются на сервер.

## Правила
- Группировка по точному совпадению D:G: наименование, размер, цвет, артикул продавца.
- Каждая исходная строка — одна штука. Разные размеры и цвета остаются отдельными.
- Если в одном задании есть Beltanee и BeltaneMan, меню загрузки позволяет скачать единый PDF или два отдельных PDF по брендам.
- Сначала позиции идут по маршруту сборщика: `211_Кбрюки_жилет` → `24_К_Велюр` → `216_К_Замша` → `29_К_Вельвет№2` → `215_КардиганШТ` → `210_Комбез` → `26_П_Вельвет№1` → `26_П_Вельвет№4` → `26_П_№12`.
- Маршрут определяется по артикулу продавца: точное совпадение или начало артикула с продолжением через `_` (например, цвет). Внутри каждой группы сохраняется порядок первого появления позиции. Остальные артикулы следуют после маршрута в исходном порядке. Правило действует в предпросмотре, едином PDF и отдельных PDF по брендам.
- Excel и PDF обрабатываются в браузере; файлы не отправляются на сервер.
- Поддерживаются .xlsx и .xls до 30 МБ, одно сборочное задание в книге.

## Разработка
Node.js 24, pnpm 11.19.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
pnpm sync-pages
```

## Публикация
Workflow автоматически проверяет и публикует main. Собранная версия также хранится в корне репозитория для режима публикации из ветки.
Адрес: https://golunovoleg111-rgb.github.io/FBS-CONVERTER/

Исходные задания пользователей и PDF не хранятся в репозитории.
