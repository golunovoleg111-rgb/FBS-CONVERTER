# Сборка FBS

Загрузите сборочное задание Excel WB, проверьте сводную таблицу и скачайте PDF A4 для печати.

## Правила
- Группировка по точному совпадению D:G: наименование, размер, цвет, артикул продавца.
- Каждая исходная строка — одна штука. Разные размеры и цвета остаются отдельными.
- Если в одном задании есть Beltanee и BeltaneMan, меню загрузки позволяет скачать единый PDF или два отдельных PDF по брендам.
- Сохраняется порядок первого появления позиции.
- Excel и PDF обрабатываются в браузере; файлы не отправляются на сервер.
- Поддерживаются .xlsx и .xls до 30 МБ, одно сборочное задание в книге.

## Разработка
Node.js 24, pnpm 11.19.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
```
